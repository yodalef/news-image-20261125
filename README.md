A Python program that sums up 25 November 2026's world news in a single 1024x1024 PNG infographic: six headline cards (the Strait of Hormuz tanker incident, Russian strikes on Ukraine, Gaza, Sudan, the Solomon Islands-Australia treaty, and COP31) plus a footnote strip. Deterministic and offline: no network use, and running it twice writes identical bytes.

## Run it

```sh
pip install Pillow
python3 main.py
```

Writes the image to /output/entry.png (or ./output/entry.png when /output is not writable).
